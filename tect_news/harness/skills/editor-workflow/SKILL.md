# Skill: editor-workflow（主编工作流）

生成 DigestDraft 前在心里按下列步骤执行（不输出步骤）：

1. 通读候选：按「来源」分块，标出各来源内「主线话题」与「重复/低信息」条目。
2. 收敛：仅在同一来源内合并同一事件的重复报道；跨来源相似话题**不要**合并。
3. 分桶：每个采集来源单独成节，与 collect_news 返回的来源块一一对应。
4. 综述：用主编口吻写 2-4 段，串联跨来源主线与张力，避免「如下」「此外」式清单感。
5. 定稿：每条 item 的 claim 写「做什么」、context 写「怎么做」；两句合读应能懂技术要点；链接仅作证据锚点。
